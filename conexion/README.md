-Este proyecto trata de un sistema compra y ventas de una tienda llamada LineaSport , es en entorno web utilizando el lenguaje de java
Contiene campos de clientes,productos,personales,etc. Para agregar,eliminar y modificar
Tambien vamos a incluir medidas de seguridad como por ejemplo encriptado de contraseña, proteccion contra inyecciones SQL
Tambien correciones de errores en la base de datos para evitar problemas de eliminacion causado por las claves primarias y secundarias con advertencias claras

-Pasos para ejecutar el proyecto
Instalar y abrir XAMPP.
Iniciar el servicio MySQL desde el panel de control de XAMPP.
Crear la base de datos e importar los scripts necesarios.
Instalar y configurar Apache Tomcat.
Configurar la conexión del proyecto con la base de datos MySQL.
Agregar el controlador JDBC de MySQL al proyecto.
Abrir el proyecto en el entorno de desarrollo (por ejemplo, NetBeans).
Compilar y verificar que no existan errores.
Desplegar el proyecto en Apache Tomcat.
Iniciar Tomcat y ejecutar la aplicación desde el navegador.
Verificar el correcto funcionamiento de los módulos, formularios y conexión con la base de datos.
